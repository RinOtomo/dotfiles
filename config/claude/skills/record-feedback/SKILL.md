# Feedback 記録スキル

ユーザーからのフィードバックを `~/.claude/docs/feedback/` に記録し、`overview.md` を更新する。

## 前提

- 記録判定ロジック（自動判定・確認・除外の基準）は `rules/incorporate-user-feedback.md` に定義済み。本スキルは記録の実行手順のみを担う。
- 既存エントリと同一の指摘は記録しない。実行前に対象ファイルを読んで重複を確認する。

## 実行手順

### 1. 分類

会話から指摘の要点を抽出し、以下のカテゴリに分類する。

| カテゴリ     | ファイル             | 判定基準                     |
| ------------ | -------------------- | ---------------------------- |
| 出力形式     | `output-format.md`   | 出力スタイル、文体、応答方法 |
| コードスタイル | `code-style.md`      | コード記述、命名、構造       |
| ツール使用   | `tool-usage.md`      | ツール選択、呼び出し方       |
| 作業フロー   | `workflow.md`        | 作業手順、実行順序           |
| ルール管理   | `rule-management.md` | CLAUDE.md、feedback 自体     |

該当なしの場合は英小文字で新規ファイルを作成する。

### 2. 対象ファイル末尾に追記

```markdown
### [YYYY-MM-DD] [行動指向の短いタイトル]

**指摘内容**: 問題の要約（1〜2行）

**適用ルール**: 今後の行動規則（箇条書き可）
```

### 3. overview.md を更新

該当行の件数と最終更新日を更新する。

```markdown
| [カテゴリ名] | [file.md](./file.md) | [件数] | [YYYY-MM-DD] |
```

### 4. 完了報告

```
✅ Feedback を記録しました
- **カテゴリ**: [category]
- **ファイル**: [filename.md]
- **件数**: [n件目]
```
